# Как проверить выпуск вручную

Установщик и программа сами проверяют каждый выпуск, и ничего делать руками не нужно. Эта страница — для тех, кто хочет убедиться сам,
что скачанный файл сделан проектом и не изменён по пути.

## Из чего состоит выпуск

На странице выпуска (`https://github.com/prankyman/wyo/releases`) лежат шесть файлов:

| Файл                 | Что это                                                                                     |
| -------------------- | ------------------------------------------------------------------------------------------- |
| `wyo_linux_amd64`    | Программа для процессоров x86_64 (большинство серверов).                                    |
| `wyo_linux_arm64`    | Программа для процессоров ARM (aarch64).                                                    |
| `install.sh`         | Установщик.                                                                                 |
| `VERSION`            | Номер версии одной строкой.                                                                 |
| `checksums.txt`      | Контрольная сумма SHA-256 каждого из четырёх файлов выше.                                   |
| `checksums.txt.sig`  | Подпись файла `checksums.txt` ключом проекта (Ed25519, 64 байта).                            |

**Контрольная сумма** — короткий текст, вычисленный из файла: если в файле изменится хоть один байт, сумма будет другой. **Подпись** —
текст, который может сделать только владелец закрытого ключа проекта, а проверить — любой, у кого есть открытый ключ. Подписан один файл,
`checksums.txt`, а он уже ручается за остальные: поэтому проверка всегда идёт в одном порядке — сначала подпись списка, затем сумма
каждого файла по этому списку.

## Открытый ключ

Открытый ключ проекта лежит в репозитории: `internal/release/keys/2026-1.pem`. Тот же ключ записан в установщике и в программе. Сохраните
его в файл `wyo-release.pem`:

```
-----BEGIN PUBLIC KEY-----
MCowBQYDK2VwAyEAKAD2JS/mnf2iy29lFfyBMY02Fq/bq+kc1wuNwNH+aBc=
-----END PUBLIC KEY-----
```

Когда ключ проекта когда-нибудь сменится, новый ключ придёт в выпуске, подписанном ещё старым ключом, и появится в той же папке рядом со
старым; программа принимает выпуск, подписанный любым ключом этой папки.

## Проверка

Нужен OpenSSL версии 3 или новее (`openssl version`).

```
curl -fsSLO https://github.com/prankyman/wyo/releases/latest/download/checksums.txt
curl -fsSLO https://github.com/prankyman/wyo/releases/latest/download/checksums.txt.sig
curl -fsSLO https://github.com/prankyman/wyo/releases/latest/download/wyo_linux_amd64

openssl pkeyutl -verify -rawin -pubin -inkey wyo-release.pem -in checksums.txt -sigfile checksums.txt.sig
sha256sum --check --ignore-missing checksums.txt
```

1. Первая проверка должна напечатать `Signature Verified Successfully`. Если она печатает что-то другое, список сумм сделан не проектом
   или изменён — дальше не продолжайте и файлы не запускайте.
2. Вторая должна напечатать `wyo_linux_amd64: OK` (и `OK` для каждого другого скачанного файла). `--ignore-missing` пропускает файлы
   списка, которые вы не скачивали. Если напротив файла стоит `FAILED`, файл изменён — удалите его.
