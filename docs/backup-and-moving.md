# Резервные копии и переезд на другой сервер

Программа хранит всё в одном файле базы данных `/var/lib/wyo/wyo.db`. Ключи маркетплейсов лежат в нём в зашифрованном виде; ключ
шифрования — отдельный файл `/var/lib/wyo/secret.key`.

## Какие копии делает программа

- **Каждую ночь**, в случайную минуту, — `/var/lib/wyo/backups/wyo-<дата>.db`, например `wyo-2026-11-17.db`. Хранятся семь последних, то
  есть копии за неделю; более старые удаляются, чтобы копии не заняли весь диск.
- **Перед каждым обновлением** — `/var/lib/wyo/backups/wyo-before-update-<версия>.db`. Копия делается, пока wyo ещё работает, и только
  потом wyo останавливается для замены программы. Если новая версия не запустится, программа сама вернёт эту копию; изменения,
  сделанные за секунду-две между копией и остановкой, при этом теряются. Хранятся три последние такие копии: лишние удаляются сразу
  после удачного обновления.
- **Когда вы попросите** — кнопкой «Сделать копию сейчас» на странице «Настройки», в разделе «Резервные копии», или командой
  `sudo wyo backup`.

Копия делается, пока программа работает, и всегда целая: в неё попадает база в одно мгновение, без наполовину записанных изменений.

## Почему ключевой файл не входит в копию

Если копия базы попадёт в чужие руки, ключи маркетплейсов из неё не прочитать без ключевого файла. Поэтому ключевой файл хранят
отдельно, и **один раз** копируют в надёжное место, например в менеджер паролей:

```
sudo base64 /var/lib/wyo/secret.key
```

Без ключевого файла копия всё равно восстанавливается — сохранятся настройки и всё остальное, — но ключи маркетплейсов придётся ввести
заново, потому что расшифровать старые нельзя.

## Как вернуть копию

Копию возвращают, только когда программа остановлена: иначе работающая программа могла бы записать что-то поверх возвращённого файла.

```
sudo systemctl stop wyo
sudo -u wyo wyo restore /var/lib/wyo/backups/wyo-2026-11-17.db
sudo systemctl start wyo
```

`wyo restore` сначала откладывает текущую базу рядом (в `backups/`), затем ставит копию на её место. Если программа ещё работает,
команда откажется и скажет, что её нужно сначала остановить.

## Как переехать на другой сервер

1. **На новом сервере** направьте на него доменное имя (README, раздел 3) и установите wyo тем же установщиком (README, раздел 5).
   Логин и пароль можно задать любые: их заменит перенесённая база.
2. **На старом сервере** сделайте свежую копию и остановите программу:

    ```
    sudo wyo backup
    sudo systemctl stop wyo
    ```

3. **Перенесите два файла** — свежую копию из `/var/lib/wyo/backups/` и `/var/lib/wyo/secret.key` — на новый сервер, например командой
   `scp` (она копирует файлы между серверами через тот же `ssh`). На новом сервере положите их в домашнюю папку.
4. **На новом сервере** остановите программу, поставьте ключевой файл и копию, запустите:

    ```
    sudo systemctl stop wyo
    sudo install -o wyo -g wyo -m 600 ~/secret.key /var/lib/wyo/secret.key
    sudo -u wyo wyo restore ~/wyo-2026-11-17.db
    sudo systemctl start wyo
    ```

    `install … -m 600` кладёт файл так, что читать его может только пользователь `wyo`: ключевой файл никто другой видеть не должен.

5. Откройте адрес в браузере и войдите прежним логином и паролем. После того как всё работает, на старом сервере можно удалить программу:
   `sudo bash install.sh --uninstall --purge`.
